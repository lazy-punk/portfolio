# Ojas Patil - AI Engineer & ML Researcher Portfolio

A modern, dark-themed portfolio website showcasing AI/ML projects, experience, and achievements. Built with React, Tailwind CSS, and Framer Motion for smooth animations.

## 🚀 Features

- **Dark Futuristic Theme** with neon accent colors (electric blue, cyan, purple)
- **Animated Background** with particle network and grid visualization
- **Smooth Scroll Animations** using Framer Motion
- **Fully Responsive** across all devices
- **Interactive UI** with hover effects and transitions
- **SEO Optimized** with proper meta tags

## 📋 Sections

1. **Hero Section** - Animated typing effect with call-to-action buttons
2. **About Me** - Education, bio, and key highlights with statistics
3. **Skills & Technologies** - Animated skill bars organized by category
4. **Featured Projects** - Showcase of major ML/AI projects with impact metrics
5. **Experience Timeline** - Work history with achievements
6. **Achievements** - Competition rankings and recognitions
7. **Certifications** - Professional certifications with grades
8. **Contact** - Contact form and social links

## 🛠️ Tech Stack

- **Frontend**: React 19.2.0
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Build Tool**: Vite
- **Language**: JavaScript (JSX)

## 📦 Installation

1. Clone the repository:
```bash
git clone <repository-url>
cd portfolio_p2
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Build for production:
```bash
npm run build
```

5. Preview production build:
```bash
npm run preview
```
